# LAVi-SPICA

**LAVi-SPICA** は、プログラミングを初めて学ぶ大学生のためのPython基礎学習アプリです。

**SPICA** は **Structured Python Interactive Course and Activities** の略です。星を一つずつ結んで星座を見つけるように、解説を読み、短いコードを書き、実行結果を確かめながら、Pythonの考え方を順番に身につけます。

ブラウザ上でPythonを実行できるため、端末へPythonをインストールする必要はありません。授業中の演習だけでなく、欠席した回の補習や自宅での復習にも利用できます。

## 学べること

| 学習段階 | 主な内容 |
|---|---|
| Pythonの第一歩 | 変数、型、`print()`、f-string |
| データをまとめる | `list`、`dict`、`tuple`、メソッド |
| 計算を繰り返す | `math`、`range()`、`for` |
| 条件で処理を変える | 比較演算、`if`、論理演算、`for`と`if` |
| 処理を再利用する | `def`、引数、`return`、デバッグ |
| データを計算する | オブジェクト、class、NumPy、配列演算 |
| データを読み解く | ファイル入出力、欠損値、保存、Matplotlib |

各lessonには、次の内容があります。

- 初学者向けの詳しい解説と文法の形
- 一行ずつ読み解く例題
- 実行前に結果を予想する活動
- ブラウザ内のPythonエディタ
- 短い変数名から始める練習問題
- ヒント、解答例、自動確認
- 事後学習問題と、よくあるエラーの説明

## 学習の進め方

1. **学習コース**からlessonを開き、最初に「このlessonのゴール」を確認します。
2. **自習用ガイド**で、文法の意味と基本形を読みます。
3. 例題の出力を予想してから、コードをエディタへ読み込みます。
4. **実行**を押し、予想と結果を比べます。
5. 値や文字列を一か所だけ変え、もう一度実行します。
6. 練習問題へ進み、分からないときだけヒントを開きます。
7. 最後に、仕組みを自分の言葉で説明します。

コードを一度で完成させる必要はありません。エラーが出たときは、最後の行、行番号、変数名、引用符、括弧、インデントの順に確認してください。

## 利用方法

授業で案内されたLAVi-SPICAのURLをブラウザで開きます。ホーム画面の「次のlessonへ」または「学習コース」から、lesson 01より順番に進めてください。前のlessonで学んだ書き方を、次のlessonでも繰り返し使います。

## 動作と保存

- 初回のPython実行時にはインターネット接続が必要です。
- NumPyやMatplotlibは、使用するlessonで自動的に準備されます。
- 学習進捗、コード下書き、予想、メモは使用中のブラウザへ保存されます。
- ブラウザのデータを削除すると学習記録も消えるため、「進捗・保存」からバックアップできます。
- 授業で確認テストのリンクが配布された場合は、そのリンクを直接開いて回答します。

詳しい操作は [学生向けガイド](docs/STUDENT_GUIDE.md) を参照してください。

## 対応環境

最新のGoogle Chrome、Microsoft Edge、Firefox、Safariを推奨します。スマートフォンでも閲覧できますが、コード入力にはキーボードを使えるPCまたはタブレットが適しています。
