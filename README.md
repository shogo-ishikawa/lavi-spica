# LAVi-SPICA

LAVi-SPICA（Structured Python Interactive Course and Activities）は、プログラミングを初めて学ぶ人のためのブラウザ版Python基礎教材です。**予想する → 実行する → 結果と理由を確かめる → 少し変えて再確認する**活動を通して、変数からNumPy・データ解析・可視化まで学びます。端末へのPythonのインストールは不要です。

## 学べること

- 変数、代入、型、四則演算、`print()`、f-string
- list、dict、tuple、添字、メソッド
- `math`、`range()`、for、if、比較・論理演算
- 関数、引数、`return`、デバッグ
- オブジェクト、class、NumPy配列と配列演算
- CSV、欠損値、集計、保存、Matplotlib

## 2つの学習モード

- **通常学習モード**：詳しい説明、例題活動、練習問題、事後学習を順に進めます。例題では、予想、コードの実行、理由の自己確認、指定変更または自由実験を別々に確認できます。
- **講義補助モード**：授業で扱ったトピックだけを選び、短い振り返りと必修練習へ進みます。トピックごとに対応する講義資料を表示するため、mathとrangeのように資料が異なる内容も正しい資料を選べます。

講義資料のColabは**履修者限定**です。授業のGoogle Classroomへ参加しているGoogleアカウントで開いてください。公開PDFには**一般公開・PDF**と表示されます。Colabを閲覧できない場合も、アプリ内の説明と問題は利用できます。

## 基本的な使い方

1. lessonの到達目標と説明を読みます。
2. 例題の出力、値、型、反復回数などを実行前に予想します。
3. 例題をエディタへ読み込み、実行結果と予想を比べます。
4. 解説を読み、処理順を自分で確認します。
5. 指定された変更課題、または自由実験を行って再実行します。
6. 練習問題と事後学習で理解を確かめます。

詳しい画面操作と確認テストの受験方法は[学生向けガイド](docs/STUDENT_GUIDE.md)を参照してください。

## 保存方法と更新時の注意

lesson完了、例題ごとの予想・編集コード・確認状態、練習問題の下書きと履歴はブラウザの`localStorage`へ自動保存されます。通常の再読み込み、画面モードの切り替え、アプリ更新では削除されません。「進捗・保存」からJSONを書き出すと、バックアップや別端末への移行ができます。

画面左下にはアプリの版とbuild IDが表示されます。更新案内が出た場合は、入力内容が保存されたことを確認してから必要に応じて再読み込みしてください。更新のためにサイトデータ全体を削除する必要はありません。サイトデータの削除、別ブラウザ・別オリジンの利用、端末の初期化では記録を引き継げないため、先に進捗JSONを書き出してください。

## 動作環境

最新版のGoogle ChromeまたはMicrosoft Edgeを推奨します。FirefoxとSafariでも利用できます。PythonはPyodideによりブラウザ内のWeb Workerで実行します。初回実行時は実行環境や必要なパッケージを取得するため、ネットワーク接続と少しの待ち時間が必要です。

## データとプライバシー

通常学習の進捗やコードは端末内に保存され、自動的に公開されません。確認テストを利用する授業では、学生用アカウント、学籍情報、回答、認証状態が授業用クラウドへ送信される場合があります。受験画面の案内と授業担当者の指示を確認してください。教材内の外部Colab・PDFを開いた場合は、各提供元の利用条件が適用されます。

## 公開サイトの構成

GitHub Pagesはワークフローで列挙された学生用アプリのファイルだけを配信します。ソースコード、テスト、一般的なビルド手順は公開リポジトリで確認できます。公開確認はNode.js 20以降で`npm ci`、`npm test`を実行します。
