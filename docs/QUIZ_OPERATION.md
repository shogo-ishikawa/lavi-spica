# 20分小テスト運用ガイド

## 1. 標準設定

- 時間：20分
- 問題数：10問
- 範囲：前回session
- Seed：`YYYY-MM-DD-session-N`のように授業日と範囲を含める
- 配布：教員モードで生成したURLをLMSへ掲載
- 提出：結果JSON

各sessionには14問あり、同じ範囲でもSeedを変えると問題選択・順序を変えられます。

## 2. 授業前

1. 教員モードを開く
2. 出題範囲を選ぶ
3. 制限時間20分、問題数10問を確認
4. Seedを設定
5. URLをコピー
6. 新しいtabでURLを確認
7. LMSへ掲載

## 3. 授業冒頭

1. 学生へURLを開かせる
2. 学籍番号・氏名を確認
3. 一斉に開始
4. 残り2分でtimerが警告表示になる
5. 20分で自動提出

早く提出した学生には、誤答解説を読み、誤答理由を一つ記録させます。

## 4. 結果提出

学生は結果画面の「結果JSON」を押し、LMSへ提出します。ファイル名には学籍番号とquiz IDが含まれます。

結果JSONの主な項目：

```text
profile.studentId
profile.name
scope / scopeName
score / maxScore / percent
startedAt / submittedAt / durationSeconds
seed
questionIdごとのanswer / correct / points
```

## 5. 教員側の集計

1. LMSから結果JSONをまとめて取得
2. 教員モードの「JSONを追加」で複数選択
3. 学籍番号、氏名、範囲、得点、提出時刻を確認
4. 「集計CSV」を書き出す

同じquiz IDを再読込した場合は重複を除きます。

## 6. 欠席・追試

- Seedを変更して別URLを作る
- 範囲と問題数は同じにする
- 受験時間を記録
- 追試であることをLMS側に記録

## 7. 採点上の注意

この小テストは静的Webアプリです。問題文と正答情報は配信ファイル内にあるため、次の用途を想定します。

適切：

- 毎回の理解確認
- 反転学習
- 誤概念の発見
- 授業内で監督される小テスト
- 成績の一部を占める低〜中stakes評価

不適切：

- 無監督で高い比率を占める定期試験
- 問題漏洩を厳格に防ぐ必要がある試験
- 本人確認やアクセス制御を要する試験

高stakes評価には、LMSの認証、server-side問題配信、受験ログ等を使用してください。
