# LAVi-SPICA 学生向けガイド

LAVi-SPICAでは、文章を読むだけでなく、**予想する → 書く → 実行する → 比べる → 説明する**という順序でPythonを学びます。

## 1. 最初に開く場所

ホーム画面の「次のlessonへ」または左側の「学習コース」を選びます。lessonは01から順に進めると、前の内容を使いながら新しい文法を学べます。

学習記録は現在使用しているブラウザへ自動保存されます。同じPCでも、別のブラウザやシークレットウィンドウを使うと別の記録になります。

## 2. lessonの読み方

### このlessonのゴール

最初に、lessonを終えたときに何ができればよいかを確認します。すべてを暗記するのではなく、「コードを見ながら説明できる」「値を変えて動かせる」ことを目標にします。

### 自習用ガイド

文法の役割、基本形、コード例を順に読みます。コード内の記号にも意味があります。

- `=` は、右側の値を左側の変数へ代入します。
- `()` は、関数を呼び出すときや引数をまとめるときに使います。
- `[]` は、listの作成や要素の取り出しに使います。
- `{}` は、dictの作成やf-string内の式に使います。
- `:` の次の行は、通常インデントして処理のまとまりを示します。

分からない用語は「資料・用語集」から確認できます。

### 一行ずつ読む例題

最初からコード全体を理解しようとせず、上の行から順に読みます。

1. その行で新しい変数が作られるか。
2. 右辺の計算結果は何か。
3. 変数の値が更新されるか。
4. `print()`で何が表示されるか。
5. `for`や`if`の内側はどの行か。

「少し変えて試す」に書かれた変更を行うと、文法と結果の関係が分かりやすくなります。

## 3. Pythonエディタの使い方

「この例題を右のエディタへ」を押すと、コードがエディタへ入ります。実行前に、表示される内容や変数の値を予想してください。

- **実行**：コードを動かします。`Ctrl + Enter`または`⌘ + Enter`でも実行できます。
- **停止**：終わらない繰り返しなどを中断します。
- **初期化**：lessonの開始コードへ戻します。
- **コピー**：コードをクリップボードへコピーします。
- **コンソール**：`print()`の出力やエラーを表示します。
- **変数**：実行後の主な変数名、型、値を表示します。
- **図**：Matplotlibで作成した図を表示します。
- **生成ファイル**：コードが作成した小さなファイルを保存できます。

初回の実行ではPython環境を読み込むため、少し時間がかかる場合があります。

## 4. 練習問題への取り組み方

練習問題では、`x`、`n`、`r`、`nums`などの短い変数名を中心に使います。最初は問題の処理に集中し、慣れてから目的が分かる名前へ書き換えてください。

次の順で取り組みます。

1. 問題文を読み、入力と出力を一文で整理する。
2. 開始コードを開く。
3. まず1〜3行だけ書き足す。
4. 実行して、エラーまたは出力を読む。
5. 必要なときだけヒントを一つ開く。
6. 合格後に解答例と比べ、別の書き方がないか考える。

自動確認は、出力や必要な構文の最低条件を確認します。合格しない場合でも、考え方が大きく間違っているとは限りません。出力の空白、改行、変数名、必要な関数を確認してください。

## 5. エラーが出たとき

エラー画面の最後の行に、エラーの種類と手掛かりが表示されます。

| エラー | 主な確認点 |
|---|---|
| `SyntaxError` | 引用符、括弧、コロン、文法の並び |
| `NameError` | 変数名の綴り、代入より前に使用していないか |
| `TypeError` | 数値と文字列など、型の異なる値を直接計算していないか |
| `IndexError` | listやtupleの範囲外の位置を指定していないか |
| `KeyError` | dictに存在しないキーを指定していないか |
| `IndentationError` | `for`、`if`、`def`の内側が同じ幅で字下げされているか |

一度に多くの場所を直さず、エラーが示した行の前後を一か所ずつ修正して再実行します。途中の値が分からないときは、確認したい場所へ一時的に`print()`を追加します。

## 6. 事後学習

事後学習では、解答例を開く前に自分の言葉で答えます。文法の名前だけでなく、処理の順序や結果が変わる理由を説明してください。

良い説明の例：

> `range(5)`は0から4までの整数を順に作る。5はstopなので含まれない。そのためfor文の本体は5回実行される。

まだ曖昧な点は、lesson内の「自分の説明・疑問メモ」へ残します。

## 7. 進捗の保存

「進捗・保存」では、lessonの完了数、練習問題の合格数、コード下書きを確認できます。

大切な記録は「進捗JSONを書き出す」で保存してください。別の端末やブラウザでは「進捗JSONを読み込む」から復元できます。読み込み前の記録は置き換わるため、必要なら先に現在の記録も書き出します。

## 8. 授業当日の確認テスト

確認テストは通常の学習画面には表示されません。授業当日に教員から配布された専用リンクを開きます。

1. 学籍番号と氏名を入力します。
2. 制限時間と問題数を確認して開始します。
3. 回答はブラウザへ一時保存されます。
4. 提出後にJSONファイルを保存します。
5. 指定されたLMSや提出先へJSONファイルを提出します。

テスト中は、同じリンクを別のタブで開いたり、ブラウザのデータを削除したりしないでください。
