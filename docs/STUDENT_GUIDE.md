# 学生向け利用ガイド

## 1. 最初の5分

1. ChromeまたはEdgeで授業用URLを開きます。
2. 「学習コース」を選び、教員が指定したlessonを開きます。
3. 右側のPython実習エディタを確認します。
4. 教員の指示があるまでは、すぐに実行せず「実行前の予想」を書きます。
5. **実行**を押します。初回だけPythonの準備に時間がかかります。

スマートフォンでも本文は読めますが、コード入力はPCを推奨します。

## 2. 一つのlessonで行うこと

### 解説

見出しを開いて、説明と短いコードを対応させます。すべてを暗記する必要はありません。どこを見れば確認できるかを把握してください。

### 教員と一緒に入力

完成コードを一度に貼り付けるより、短いまとまりごとに入力し、各行が何をしているか確認します。「このコードをエディタへ」を使っても構いませんが、実行前に結果を予想します。

### 実行前の予想

次のいずれかを書きます。

- 何が表示されるか
- 何回繰り返すか
- どの条件がTrueになるか
- 値を変えると、何がどちら向きに変わるか
- エラーになると考える場合、その理由

### 練習問題

「開始コードを開く」で右側のエディタへ読み込みます。実行後に最低条件を自動確認します。合格表示が出ても、コードを一行ずつ説明できるか確認してください。

### 事後学習

自分の言葉で説明してから解答例を開きます。文章が完全一致する必要はありません。重要な因果関係や用語が説明できているかを比較します。

## 3. エディタの操作

| 操作 | 方法 |
|---|---|
| 実行 | **実行**、または `Ctrl + Enter` / `⌘ + Enter` |
| 字下げ | `Tab`で半角スペース4個 |
| 停止 | 長時間計算中に**停止** |
| コピー | **コピー** |
| 開始状態へ戻す | **初期化** |

実行結果は4つのtabへ分かれています。

- **コンソール**：`print()`の出力、warning、traceback、自動確認
- **変数**：実行後の主要変数、型、配列のshape・dtype・統計
- **図**：Matplotlibで作った図
- **生成ファイル**：`np.savetxt()`、`np.save()`、`savefig()`などで作った2 MB以下のファイル

## 4. エラーの読み方

エラーが出たら、まず次を読みます。

1. エラー名：`NameError`、`SyntaxError`、`TypeError`など
2. 行番号
3. 問題と示された行
4. その行より前で作った変数の値と型

代表例：

- `NameError`：変数名の綴り、代入前の使用
- `SyntaxError`：引用符、括弧、コロン、全角記号
- `IndentationError`：`if`、`for`、`def`の内側の字下げ
- `TypeError`：その型では使えない演算や関数
- `IndexError`：list・配列の範囲外
- `KeyError`：辞書に存在しないキー

エラーが出たときに、全コードをAIへ貼って直してもらう前に、エラー名と行番号から原因候補を一つ挙げてください。

## 5. 変更と比較

一度に多数の行を変えると、何が結果を変えたか分からなくなります。

1. 元の結果を確認
2. 一つの値または一つの規則だけ変更
3. 再実行
4. 変更前後を比較
5. 「何を変え、何が変わったか」を一文で記録

乱数を使う発展課題ではSeedも記録します。

## 6. 20分小テスト

- 教員から配布されたURLを開きます。
- 学籍番号と氏名を確認します。
- 開始後、残り時間と回答数が上部に表示されます。
- 回答はブラウザのsessionStorageへ自動保存されます。
- 時間切れになると自動提出されます。
- 提出後、指定された場合は結果JSONをLMSへ提出します。

小テスト中のコード問題は、まず紙または頭の中で変数を追跡します。

## 7. 進捗のバックアップ

「進捗・保存」から進捗JSONを書き出せます。次の情報を含みます。

- 学籍番号・氏名
- lesson完了
- コード下書き
- 予想・メモ・Exit Ticket
- 練習履歴
- 小テスト履歴

個人情報を含むため、他人へ公開しないでください。別端末では同じ画面から読み込めます。

## 8. AIを使うとき

AIの使用自体を学習成果とはしません。次を説明・実行できることが必要です。

- 主要変数の意味と単位
- 反復回数
- 条件分岐がTrueになる条件
- 関数の入力と戻り値
- コードのどこを自分で変更したか
- 予想と実行結果が一致したか
- 小さい入力で検証したか

AIへ質問する前に、エラー名、該当行、期待した結果、実際の結果を書き出すと、丸投げではなく原因調査になります。
