# Tests

- `npm run check`: static content, schema, ID, version, Python AST, JavaScript syntax, path-safety checks
- `npm run validate:solutions`: executes all 46 practice solutions and evaluates their checks
- `npm run validate:quiz`: checks all 98 quiz records and executes representative answer cases
- `npm run verify`: runs all three suites

Browser smoke tests were executed during release preparation; see `docs/VALIDATION.md`.
